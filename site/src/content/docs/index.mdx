`denex-network-manager` is for local Canton/Splice development. It starts a Super Validator, one or
more regular validators, Keycloak, PostgreSQL, Nginx, and the web UIs by talking to the Docker API
directly — so you do not maintain the upstream LocalNet config tree yourself.

:::caution[Pre-1.0 beta]
This is a beta release. The API may change in minor versions (`0.x`). Check the
[changelog](/denex-network-manager/help/changelog/) before upgrading.
:::

This is the whole configuration for a two-validator network:

```yaml
version: '1.0'

validators: 2

auth:
  keycloak:
    admin: admin
    password: admin
```

```bash
dnm start
```

Every party is allocated, every user is provisioned across the ledger, Keycloak, and the Splice
wallet, and every port is assigned relative to `basePort`. Nothing downstream — no application, no
test, no CI job — needs a hardcoded port, party ID, or credential to talk to the network.
